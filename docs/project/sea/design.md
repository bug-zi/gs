## 1. 定位

大海是三层学习框架的第一层：**外部知识**。博主精选文章笔记、向 AI 提问得到的解析问答，全部复制粘贴而来；信息最多最广最复杂，不是自己写的，不完全属于自己。三层框架回答「知识存在哪、怎么流」，sea 回答「外部知识存在哪、从哪进来」。

## 2. 存储结构

`Study/sea/`，一主题一文件（gs 识别 .md）：

```
Study/sea/
├── ai/          # /AI 会话存档（自动落盘，文件名=存档时刻）
├── interview/   # 面试题正本（各项目内 interview md 迁入；自己整理的答案流向 river/spring）
├── 未分类/       # seaport 自动导入的兜底目录（AI 分类失败时落此处）
└── <主题>/       # 主题子目录自建（Go语言基础、GPT、Gin与Gee、项目-* 等），查阅按一级子目录分组
```

另：工作区根 `<root>/seaport/` 是导入投递口（见 §3 通道三），不在 sea 目录内。

## 3. 录入通道（Q3 定案：两种并存 → 2026-10-27 起三种并存）

1. **/AI 会话存档**：`/AI` 子模式内 `/save` 手动存档；离开模式（/back、/exit）时主动询问「本次 AI 会话存入大海？」，确认后整理落盘至 `sea/ai/`。详见 `ai/design.md`。
2. **文件导入目录**：外部 md 放入 `sea/inbox/`，gs 启动时检测待导入数量并提示；`/sea import` 逐个预览（前 10 行）、起标题（回车默认原文件名）、迁移至 `sea/clip/<标题>.md`，重名跳过。（2026-10-27 起被通道三的自动化取代为主用通道，机制仍保留）
3. **seaport 自动导入**（2026-10-27 新增）：工作区根 `seaport/` 放 `.md`/`.txt`，gs 启动时后台按内容 AI 分类（候选=sea 一级子目录，温度 0，批量一次调用）迁入对应主题目录，原件随迁移消失；AI 未配置/失败/目录不候选一律兜底进 `sea/未分类/`；重名自动加 `-2` 后缀绝不覆盖；零交互零配置（复用 `/AI` 的 `[ai]` 配置）。设计与实施记录见 `archive/2026-10-27-seaport自动导入-design.md`、`-plan.md`。

## 4. 命令行为（Q4/Q5 定案 + 实现核对）

| 命令 | 行为 |
|---|---|
| `/sea [关键词]` | 查阅：条目按一级子目录分组两级选择；有关键词平铺直选，唯一命中直达；选中后逐屏阅读 |
| `/sea import` | inbox → clip 整理（见上） |
| `/sea edit [关键词]` | 选择条目调起编辑器 |

seaport 自动导入无命令：gs 启动时后台执行，结果在提示符前打印明细。sea 查看按一级子目录分组，不走知识点绑定（roadmap 的 Sea 绑定字段已预留，命令层未接）。

## 5. 迁移与既有内容（Q1b/Q1c/Q2 定案，已随阶段 1 落地）

- 各项目内 interview 面试题 md 迁入 `sea/interview/` 中心正本。
- 旧 `Study/notes/` 目录取消：逐个人工判断拆入 sea（粘贴原样）或 river（已筛选整理）；`/notes` 命令由三层命令体系接替退役。

## 6. 与其他模块的关系

- **river**：摘录流动的源头（`/river add` 从 sea 选条目，出处链自动带）。
- **ai**：问答存档的落点（`sea/ai/`）。
- **show**：素材源之一（「知识」节 sea 作补充；「面试题」节以 `sea/interview/` 正本为主）。
- **review**：大海堆积提醒（出处行反查未摘录条目）的数据源。
- **全局检索 /search**：跨层查找底座，sea 全量在扫描范围内。
