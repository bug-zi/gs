# code

code（代码）模块文档目录：四层学习框架第四层「动手演示」的需求正本与 spec/plan 归属。

**使用方式**：涉及 `/code` 命令、`Study/code/` 目录、知识点级 .go 演示代码的功能，其 design.md / spec / plan 放本目录；落地或废弃的 spec/plan 移入本目录 `archive/`。

**本目录内容**：

- `design.md` — code 层需求正本（AI 起草，待开发者审核定稿）
- `archive/` — 已落地/废弃的 spec/plan 归档处

**边界**：`design.md` 的修改权在开发者；AI 只可提建议或经审核协助。绑定数据模型正本在 roadmap.toml（plan 域），跨层框架决策见 `全局/三层学习框架-design.md`（code 层为四层闭环的第四站，正本修订权在开发者）。

**首份 spec/plan**：code 层立项 spec/plan 随落地归档于 `plan/archive/2026-10-27-code层知识点演示代码-design.md`（及同名 -plan.md）——数据模型改动属 plan 域，故按创建时归属归档于彼处。
