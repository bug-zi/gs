## 1. 背景与动机（开发者原话整理）

- sea 是入口，river 是沉淀打磨区，spring 是最终精华；三层之间如何连接打通、如何让知识 sea→river→spring 流转，「似乎还没有实现」。
- 三个知识笔记区应该和 plan（Go 学习路线框架）有联系和绑定：plan 是学习路线框架，笔记需要按路线框架分类，否则是「散架的」。

## 2. 现状盘点与缺口

**已实现（学习 design.md Q4，阶段 2 已落地）**：

- 命令式流动：`/river add`（sea→river 摘录，预填出处+全文）、`/spring add`（river→spring 改写），出处链 `> 出处：<工作区相对路径>` 自动带；
- `/review` GatherTierStats 出处行反查：未摘录 sea、待改写 river 统计。

**实际使用**：sea 4 篇（GPT 迁移 2 + interview 2）、river 0 篇、spring 0 篇——主链路一次未跑。「没打通」的体感一部分来自未使用，另一部分是真实缺口：

1. **关联单向纯文本**：出处链只是条目内一行字，浏览 river 条目无法跳回 sea，也没有「归属哪个知识板块」的信息；
2. **层内平铺无结构**：`/river` `/spring` 列表即文件名堆，「散架」感的来源；
3. **roadmap.toml 尚未生成**：绑定无处安放（路线图升级轮的前置原因）。

## 3. 已确认的关键决策（brainstorming 问答记录）

| # | 问题 | 决策 |
|---|---|---|
| 1 | 绑定模型 | **方案甲：节点挂 `links` 数组**。绑定关系唯一正本在 roadmap.toml；笔记文件零改动；「笔记属于哪个节点」靠反查计算。方案乙（笔记侧加 `> 节点：` 行，节点改名即静默失效）与方案丙（双存必漂移）被否 |
| 2 | 路径规范 | **工作区相对路径**（含 `Study/` 前缀，如 `Study/river/GMP调度.md`），与出处链、`ListTierFiles` 返回值同规范。修正路线图升级 spec 原定的 Study/ 相对路径 |
| 3 | links 指向类型 | **不限制**（sea/river/spring、项目 docs/study 走读均可挂）；文件不存在时视图标 `[失效]`，不自动清理 |
| 4 | 节奏 | **两轮**：路线图升级轮先落地（本设计仅促其修订 `link`→`links`，趁 TOML 未定稿避免日后迁移），知识绑定轮随后、建立在 roadmap.toml 之上 |
| 5 | 分组范围 | `/river` `/spring` 列表按主干分组；**sea 不分组**（杂多不作主体，维持现状） |
| 6 | 流转挂载 | **从节点发起**的摘录/改写落盘即自动挂载；`/river add` `/spring add` 独立使用行为不变（不挂载），两入口并存 |
| 7 | 体验范围 | 导航联动、分类组织、流转驱动三项全做（开发者多选确认） |

## 4. 绑定模型与数据结构

```toml
[[branch.topic.node]]
title = "GMP 调度模型"
status = "doing"
links = [                        # 0~N 条，工作区相对路径
  "Study/sea/clip/GMP调度详解.md",
  "Study/river/GMP调度.md",
  "Study/spring/GMP我的理解.md",
]
```

- 一个节点挂 0~N 条笔记；一条笔记可被多个节点挂——**多对多天然成立**；
- roadmap 改名、挪枝干均发生在 roadmap.toml 内部，links 跟随，不伤笔记；
- 列表分组前缀遇**多归属**笔记：取第一个匹配主干（roadmap 顺序）做前缀，完整归属在条目视图列全；
- `GroupByBranch` 输出顺序：主干按 roadmap 内顺序，未挂载集合殿后。

## 5. 命令面（新增 2 条，改 3 处）

| 命令/改动 | 行为 |
|---|---|
| `plan link <节点关键词>` | 选节点 → 选笔记（三层笔记列表 sea→river→spring，支持关键词过滤）→ 追加进 links，原子写。唯一直达，多匹配弹 select，无参数进纯交互逐层选 |
| `plan unlink <节点关键词>` | 选节点 → 列该节点已挂笔记，多选移除，原子写 |
| `/river` `/spring` 列表 | 选项加归属前缀：`[并发编程] GMP调度.md`、`[未挂载] 随手记.md`、`[失效]` 标注链接失效的条目 |
| 条目视图（river/spring） | 页首加归属行「归属：并发编程 › GMP 调度模型」（反查，多归属列全）；pager 加 `o` 键：解析出处行，若指向工作区内存在文件则跳转继续浏览（sea→river→spring 双向链式回溯），出处缺失或文件不存在时提示不跳转 |
| `plan <主干>` 过滤视图 | 底部加「知识挂载」清单：该主干各节点及其挂的笔记，选中可直接查看/编辑 |

落地时同步：路线图升级 spec 第 5 节的子命令消歧保留字清单（`status/next/edit/done/doing/todo/add`）需增补 `link`、`unlink`，否则会被当作主干过滤关键词。

## 6. 流转驱动：从节点发起一条龙

`plan <主干>` 视图 → 选节点 → 动作菜单：

```
GMP 调度模型 [doing] · 已挂 2 条笔记
  1. 从大海摘录到此节点   （= /river add，创建后自动挂载）
  2. 从河流改写到此节点   （= /spring add，创建后自动挂载）
  3. 挂载已有笔记          （= plan link）
  4. 查看/编辑已挂笔记
```

关键差异：从节点发起的摘录/改写，`CreateEntry` 成功后自动 append 进该节点 `links` 并原子写——学完一个知识点，sea 来源、river 摘录、spring 输出零额外步骤挂成整链。

## 7. /review 三层视角扩展

GatherTierStats 追加第四类确定性统计：**未挂载笔记**——river/spring 中未被任何节点 links 指向的条目清单，与现有未摘录/待改写并列输出，同样注入 AI 提示词（AI 的归类建议顺带获得，不单做功能）。

## 8. 代码架构

延续硬性规则「命令层纯逻辑与交互壳分离」，建立在路线图升级轮产出的 `internal/roadmap` 包之上：

```
internal/roadmap/ops.go     # 扩展纯逻辑：LinkNode/Unlink（幂等去重）、
                            # OwnersOf（反查归属，返回 主干›枝干›节点 链）、
                            # GroupByBranch（文件列表按主干分组 + 未挂载集合）
internal/command/binding.go # 新建壳层：plan link/unlink 交互、
                            # [主干]/[未挂载]/[失效] 选项前缀组装、节点动作菜单
internal/command/tier_cmd.go # 改：pickTierEntry 选项加前缀；runTierView 归属行 + o 键
internal/command/plan.go     # 改：link/unlink 子命令分发、过滤视图挂载清单、菜单入口
internal/command/review.go   # 改：GatherTierStats 追加未挂载统计
```

边界划分：`roadmap` 包只管 TOML 结构与匹配分组（不 import ui、不碰文件存在性）；`[失效]` 判断（os.Stat）、pager 跳转等 IO/交互全部在 command 壳层。

## 9. 错误处理（全部静默降级，不阻塞既有功能）

| 场景 | 行为 |
|---|---|
| roadmap.toml 缺失 | `plan link/unlink` 提示「路线图尚未生成」；分组前缀、归属行、review 未挂载项省略——退回现状 |
| 挂载目标文件不存在 | 写入前提示确认（允许预挂，服务手编场景）；显示时标 `[失效]` |
| 关键词零/多匹配 | 与 `plan done` 同规则：零匹配报错列候选，多匹配弹 select |
| 重复挂载 | 幂等：提示已挂载并跳过 |
| 出处指向的文件已删 | `o` 键提示「出处文件不存在」，不跳转 |

## 10. 测试与验收

- `internal/roadmap` 单测：LinkNode 幂等去重、Unlink、OwnersOf 多节点反查、GroupByBranch 分组与未挂载集合、links 的 TOML 序列化回读；
- command 层测试：选项前缀组装、出处跳转目标解析、review 未挂载统计（交互壳不自动测，延续惯例）；
- 验收：`go build ./...` + `go test ./...` 全绿；真实工作区冒烟——挂载一条 → `/river` 见 `[主干]` 前缀 → 条目视图见归属行 → `o` 键回溯到 sea → `plan 并发` 见挂载清单 → 从节点发起摘录自动挂载。

## 11. v1 边界（不做）

- 树视图内联显示 links（树保持简洁，`plan <主干>` 过滤视图清单承担展示）；
- sea 层分组；
- 「一键跑完整条链」（每步都需人工写，无可自动化）；
- 工作区外路径的解析（相对路径只认工作区内）；
- 未挂载笔记的 AI 自动归类命令（清单入 AI 提示词后建议顺带获得）。
