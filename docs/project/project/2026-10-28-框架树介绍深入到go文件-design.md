# 框架树介绍深入到每个 .go 文件 设计

日期：2026-10-28
状态：**开发者已确认**
所属模块：project

---

## 1. 背景与动机

- `/project` → 框架树的节点介绍由 AI 逐层生成，缓存至 `.gs/structures/<项目名>.toml`。实际使用中只有根一级有介绍（如 fileforge 缓存仅 13 个根节点，深层全部缺失）。
- 原因有二：
  1. 每层一次 AI 调用，中途某层失败或被 Ctrl+C 中断后缓存非空，而 `showProjectTree` 仅在缓存为空时触发生成，残留缓存永不续齐；
  2. 生成对象含全部展示类型文件（.md/.mod/.json 等），深层密集层（如 `internal/command` 约 45 个 .go）的字符预算被无关文件头部挤占。
- 目标：介绍深入到每一级——**目录 + 每个 .go 文件**；非 .go 文件不再生成介绍。

## 2. 已确认决策（brainstorming 问答记录）

| # | 问题 | 决策 |
|---|---|---|
| 1 | 介绍对象范围 | 目录保留介绍；文件只介绍 `.go`，其余类型照常显示在树里但不生成介绍 |
| 2 | 生成策略 | 全量逐层生成 + 断点续传 + 单层容错（不采用进入目录按需生成 / 一次调用全项目） |

## 3. 设计细节

### 3.1 目标集合与缺口计算

- `internal/structure` 新增纯函数：递归收集"应介绍节点"= 全部**目录** + 全部 **.go 文件**；跳过隐藏目录与 `config.Scan.Exclude` 段名，与现有扫描规则一致。
- 进入框架树时（`showProjectTree`）：目标集合与缓存 diff 得**缺失集合**；缺失非空且 AI 已配置 → 自动续生成。
- 续生成以目录为批次：遍历全部目录（BFS），每批清单 = 该目录直接子节点中的**缺失者**；批次清单为空则跳过（不调 AI）。已有介绍的节点不重新生成、不被覆盖。
- 缓存非空也续（解决中断残留）；提示「（续生成介绍… 缺 N 节点）」，生成中仍逐层显示「（AI 分析中… <dir>）」。

### 3.2 单层容错与断点保存

- `genTreeDescriptions`：某批 AI 调用失败**不再整体中断**——记录失败批次（目录 + 错误），继续其余批次；结束时统一报告「N 批失败，可按 r 重试」。
- 每批成功即 Merge + Save（沿用现状），中断/失败不丢已生成批次。

### 3.3 `r` 重生成语义

- 按 `r`：**先清空当前子树**（`st.root` 及其全部后代节点）的缓存条目，再对该子树重新生成。
- 与自动续传分工：续传只补缺失；`r` 强制重建（介绍过时/想换口径）。根目录按 `r` = 全项目重建。
- 清除后旧的非 .go 介绍残留自然消失。

### 3.4 prompt 调整

- 每批清单只列 目录 + .go 文件，不再列其他类型文件、不再读它们的头部。
- .go 仍附 40 行文件头；总字符预算 12000 → **16000**（无 .md 挤占，密集层能覆盖更多真实内容）。
- system prompt 微调：清单即全部待介绍节点；`.go` 结合文件头写一两句、≤60 字；目录按内容概览写；只输出 JSON 数组。

### 3.5 展示与降级（不变）

- 介绍按精确 path 匹配显示在名字后；AI 未配置显示纯树；非 TTY 降级整棵树一次性打印，均不改动。

## 4. 代码架构

延续「命令层纯逻辑与交互壳分离」：

- `internal/structure/`：
  - 新增递归收集应介绍节点（目录 + .go）的纯函数（复用现有 exclude/隐藏目录规则）；
  - `StructureCache` 增加子树清除方法（按前缀删除后代节点，含自身）。
- `internal/command/project.go`：
  - 缺口 diff 与按批续生成（改造 `genTreeDescriptions` / `genLevelDescriptions`）；
  - 失败批次收集与汇总报告；
  - `r` 动作：清子树 → 重生成。
- 缓存文件格式 `.gs/structures/<项目名>.toml` 不变，旧缓存天然兼容。

## 5. 错误处理

- AI 未配置：现状不变（纯树 + 提示）。
- 全部批次失败：报错不崩，缓存保留原有内容，可重试。
- 缓存 TOML 解析失败：视为空缓存走全量生成（现状不变）。

## 6. 测试与验收

- 单测（AI 调用打桩）：
  - 目标集合收集：目录 + .go 过滤、exclude 段名、隐藏目录跳过；
  - 缺口 diff：缓存命中/缺失混合时只含缺失节点；
  - 子树清除：清除后代与自身、不影响兄弟子树；
  - 失败批次容错：某批失败后其余批次继续、汇总报告。
- 验收：`go build ./...` + `go test ./...` 通过；对 gs 实跑一次深层生成，并验证中断后再次进入自动续传。
