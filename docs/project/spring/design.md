## 1. 定位

泉水是三层学习框架的第三层：**原创输出**。自己根据学习经验亲手写出的内容——记录已学了什么、掌握了哪些知识、自己对知识点的理解。三层框架回答「知识存在哪、怎么流」，spring 回答「我自己的理解是什么」。

**泉水纪律（Q4 定案）**：只提供编辑器手写入口，不提供粘贴/导入通道（设计上引导手写，终端内无法强制）。

## 2. 存储结构

`Study/spring/`，一主题一文件；条目与 roadmap 知识点一一对应（见下），文件名默认取知识点标题。

## 3. 命令行为（Q4/Q5 定案 + 实现核对）

| 命令 | 行为 |
|---|---|
| `/spring [关键词]` | 查阅：按 roadmap 主干分组两级选择，未绑定文件归尾部「未挂载」组；有关键词平铺直选 |
| `/spring add <知识点关键词>` | 定位知识点 → 该知识点已绑定 spring 则直接打开；否则创建占位条目（占位提示行「用自己的话总结这个知识点，写完删掉本行」）→ 绑定落盘 → 调起编辑器手写 |
| `/spring edit [关键词]` | 选择条目调起编辑器 |

实现期说明：Q4 原表述为「选择器挑 river 条目改写」，实现期将入口定为**知识点驱动**（`/spring add <知识点>`）——spring 与知识点唯一绑定，绑定即关联，占位条目不带出处行；river→spring 的改写仍可在编辑器中参考 river 内容完成。

## 4. 与 roadmap 的绑定

知识点通过 `spring` 字段**唯一绑定**（0/1，重绑覆盖语义）。`/plan` 浏览器与层查看共用绑定视图；同样以磁盘为准，幽灵绑定不展示。

## 5. 与其他模块的关系

- **river**：改写素材来源（编辑器内参考）。
- **plan**：spring 是知识点「学透」的输出标志，绑定关系进 roadmap 正本。
- **show**：「知识」节 spring 条目优先展示。
- **review**：三层统计中「泉水产出统计」的数据源。
