# 内联编辑器自研:显示行导航 + CJK 软换行标记 + 列表续写

状态：**已落地（261027，`go build`+`go test` 全绿）**
所属：`全局/`（编辑能力；前案无）

- 已归档：261027 随 内联编辑器自研 落地

## 问题（实证）

`spring` 等短 md 文件走 `EditInline`（bubbles/textarea）编辑，实测三个坑：

1. **软换行断点与真实换行无法区分**。长中文行在词边界折行，如 `比如说` 与 `[5]func()` 之间的空格恰为折行点，显示上与真实换行一模一样，开发者误以为文件被折断（实际文件内容完好，已用逐键模拟验证 `Value()` 与输入一致）。
2. **↑↓/Home/End 按逻辑行移动**。实测：光标在软换行片段下方按两次 ↑，光标越过片段落进上一条逻辑行中间，继续输入的字符插错位置（`- Go语言X中`）——「打不出想要的 -」的直接原因。
3. 保存失败的错误提示永不显示（`EditInline` 读的是初始副本的 `err`，不是 `Run()` 返回的最终模型）——顺手修复。

根因在 bubbles/textarea 的软换行交互模型，升级依赖无法解决。

## 方案

替换 textarea 为自研多行编辑模型，**保留 tea 壳**（编辑器独占 alt-screen、无交错写入，本仓实测可用；REPL v2 去 bubbletea 的教训仅适用于与普通写入交错的场景）。沿用 REPL v2 的分层风格：纯逻辑与壳分离、全部可测。

### 交互语义

| 按键 | 行为 |
|---|---|
| 字符/IME/空格 | 光标处插入 |
| Enter | 换行；`- `/`* `/`+ `/`1. `/`1)` 列表行自动续写前缀（有序递增编号）；空列表项（只有前缀无内容）回车清除前缀退出列表 |
| Backspace / Delete | 删字符；行首/行尾则与相邻行合并/吞并 |
| ← → | 字符级移动，跨行边界连续 |
| ↑ ↓ | **按显示行移动**（软换行片段也算一行），视觉列粘滞 |
| Home / End | **当前显示行**首/尾（片段行首即逻辑行中段） |
| PgUp / PgDn | 整屏滚动 |
| Ctrl+V | 粘贴（bracketed paste），粘贴换行**不走**列表续写 |
| Ctrl+S | 保存退出（CRLF 风格还原，原子写） |
| Esc | 未保存先确认 (y/N)，再按确认 |

### 软换行显示规则

- 纯字符切分（按显示宽度，runewidth 计宽），**不做断词**——断点可预测，无忽长忽短。
- 延续片段渲染时加 2 空格缩进，与真实行（顶格）一眼区分。
- 整行宽度恰为 width 整数倍时补一个空片段，光标行尾有落脚格。

### 模块划分

```
internal/edit/
  wrap.go     # 纯逻辑:WrapRunes 字符切分 / Layout 显示行布局 / CursorVRow / 列宽换算（可测试）
  buffer.go   # 纯逻辑:Buffer{lines,cur,col,want} 插入/删除/断行合并/列表续写/显示行移动（可测试）
  mdedit.go   # tea 壳:editor Model 按键分流/滚动/渲染/Ctrl+S/Esc 确认/粘贴（薄）
  inline.go   # EditInline 换用新编辑器;textarea 引用移除;Run() 最终模型取 err（修坑 3）
```

### 范围外

- 撤销/重做、鼠标、查找替换、语法高亮（textarea 原本也没有，不做）。
- `go mod tidy`（textarea 移除后 bubbles 可能成为无引用依赖，是否清理由开发者决定）。

## 测试

- wrap：CJK 切分、恰好填满补空片段、空行、宽度钳制。
- buffer：插入/删除/合并、列表续写（无序/有序/空项退出）、显示行导航回归（复现「两次 ↑ 落进上上条逻辑行」场景，断言落在正确片段）。
- mdedit：按键流模拟输入列表、Esc 确认流、Ctrl+S 保存 CRLF 还原、粘贴不走续写、↑ 回归。
- 回归：`go build ./...` + `go test ./...` 全绿。
