# 交互壳配色美化：面板 / 提示符 / banner / 选择列表 / 反馈色

日期：2026-10-28
状态：**已落地（2026-10-28，`go build`+`go vet`+`go test ./...` 全绿；真机冒烟待开发者）**
- 已归档：261028 随 交互壳配色美化落地
所属：`全局/`（交互壳视觉；依赖：REPL 候选面板交互升级同日落地）

- 需求来源：开发者选定三项美化（候选面板、提示符+banner、选择列表统一+反馈色）；`/help` 着色明确不做。
- 原则：沿用既有暖金低饱和主题族（220 金 → 179 赭 → 180 麦 → 144 沙 + 203 红），不引入新彩亮色；无 emoji 图标；手绘 ANSI 热路径与 lipgloss 常规输出并存。

## 一、统一色板（ui 包单点定义）

新增 `internal/ui/ansi.go`——手绘 ANSI 常量（四处选择列表/面板共用，主题值单点维护）：

| 常量 | 值 | 用途 |
|---|---|---|
| `ANSIGold` | `38;5;220` + bold | 品牌字/选中行箭头 |
| `ANSIOchre` | `38;5;179` | banner 标签 |
| `ANSIOchreBold` | `38;5;179` + bold | ai 提示符 |
| `ANSIBright` | `38;5;255` | 选中项文字 |
| `ANSIMid` | `38;5;245` | 未选项 |
| `ANSIIdle` | `38;5;240` | 箭头/提示/延迟提示 |
| `ANSISelBg` | `48;5;236` | 选中行微底 |
| `ANSIItalic` / `ANSIReset` | `3` / `0` | 提示行斜体 / 复位 |

`render.go` 增 lipgloss 助手：`ui.Gold`（金粗）、`ui.Label`（赭）、`ui.OK`（144 沙，成功语义，与 Err 对称）。

## 二、选中行统一样式（替代整行反白 `\x1b[7m`）

- 有箭头的列表（repl 候选面板、prompt 询问框）：`ANSIGold ❯ reset + 空格 + ANSISelBg + ANSIBright 文本 reset`
- 无箭头的行选择（planview 浏览器、project 框架树）：`ANSISelBg + ANSIBright 文本 reset`
- 未选项：面板用 `ANSIMid`；两个树视图素文本不变
- 输入行光标反白（`\x1b[7m` 光标字符）**保留**——那是光标不是选中
- 延迟参数提示行：`ANSIIdle + Italic`

## 三、提示符与 banner 品牌色

- 提示符：`gs ❯ ` / `ai ❯ `（SetPrompt 传素文本，rawReader.SetPrompt 内着色——gs 金粗、ai 赭粗、箭头暗灰）；`plainReader` 降级仍素文本
- 宽度修正：新增 `plainWidth`（剥离 ANSI CSI 后计宽）；`buildInputLineFit` 返回列与 `drawLocked` 的 avail 改用它，素文本提示符结果不变
- Esc 判定：rawReader 增 `promptName`（素文本首词）替代 `HasPrefix(r.prompt, "ai")`（着色后前缀判定失效）
- banner：`gs` 金粗 + · 暗灰 + 根路径暗灰；信息行标签（当前断点/目标/上次学习）赭色，值不动

## 四、反馈语义色

`ui.OK`（144 沙）应用于纯成功反馈 7 处：repl.go 已存档、aisave.go 已存档、logs.go 已创建、plan.go 已更新/已标记、tier_cmd.go 已导入/已创建并绑定（×2）。已是 Dim 的中性提示（project.go 已创建等）不动；编辑器状态行不动。
