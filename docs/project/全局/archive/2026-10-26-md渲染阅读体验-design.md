# gs Markdown 渲染阅读体验（标题样式 + 全入口统一 + 行级分页）— 设计文档

日期：2026-10-26
状态：**已落地**（`go build ./...` + `go test ./...` 全绿）
- 已归档：261026 随 md 渲染阅读体验 落地
所属：跨模块全局改动（internal/ui 渲染核心 + logs / sea / river / spring / show / search 六处命令接入），spec 按机制存放于 `全局/`
背景：开发者在查阅态打开笔记看到 `## 3. 为什么要把完整的读—改—写放在锁内` 等未渲染原文，要求提升阅读体验

---

## 1. 背景与根因（已实测验证）

gs 已有 glamour 渲染基础设施（`internal/ui/render.go` 的 `RenderMD`，glamour v1.0.0 已在依赖），但存在四层问题：

| # | 根因 | 证据 |
|---|---|---|
| 1 | **glamour 标准样式的标题自带 `##` 字面前缀**（设计如此：dark 样式渲染后是 ANSI 包裹的 `## 3. ...`，ascii/notty 则是素文本） | 本机探针实测：`WithStandardStyle("dark")` 渲染 `## 标题` 输出仍含 `## ` 子串 |
| 2 | `WithAutoStyle()` 探测终端背景失败时回落 ascii/notty，完全无样式 | 非 TTY 环境 auto 实测回落 notty（素文本 + `## ` 前缀） |
| 3 | 多入口未接渲染：`/show` 知识节、日志节、面试节（`show.go` 直接 `truncateLines` 拼 raw text）；`/search` 命中行原样打印 | show.go:71-77、127；logs.go viewByKeyword |
| 4 | 长文档（如面试题笔记数百行）一次打印刷屏滚走；换行宽度固定 90 列 | runViewPager / runShowPager 全文 `Fprintf` |

## 2. 核心决策

| 决策点 | 结论 |
|---|---|
| 渲染范围 | **全部入口统一渲染**：logs / sea / river / spring / plan 查阅态 + `/show` 各节 + `/search` 命中行 |
| 样式策略 | **自定义 glamour `ansi.StyleConfig`**（方案 A）：h1–h6 去掉 `#` 前缀，用颜色层级 + 加粗区分；显式指定样式，**弃用 `WithAutoStyle`** |
| 配色 | 与现有点缀色同族的低饱和暖色系：h1/h2 用 220 黄 + bold，h3 用同族浅一档（实施时在 179 一带定档），h4–h6 递减为仅加粗；正文/列表/引用/表格中性灰白；代码块柔和配色。无 emoji、无彩亮饱和色（硬性规则 2/4） |
| 长文处理 | **行级分页**（轻量）：保持现有非 TUI 架构（bufio 读 stdin），不引入 bubbletea 全屏 TUI |
| 终端深浅 | **只做深色一套**（按开发者当前深色终端调色；若后续需要浅色再加深色/浅色双变体） |
| 终端宽度 | `min(终端实际宽度, 100)`，取不到时 90；渲染器按宽度缓存 |
| 截断策略 | `/show` 的 60 行截断维持不动（分页已解决长度问题，范围控制） |

备选否决：dark 标准样式（标题 `##` 前缀仍在，核心诉求未解决）；goldmark 自写渲染器（重造轮子）；bubbletea viewport 全屏滚动（体验好但 REPL 生命周期改动最大，否决）。

## 3. 改动单元

### ① internal/ui/render.go — 渲染核心

- 新增 `gsStyle ansi.StyleConfig`（以 glamour dark 结构为底定制，见上表配色）
- `RenderMD(src string)` 签名不变；内部改为：取终端宽度（`golang.org/x/term`，已在依赖）→ `min(w, 100)`，默认 90 → 按 width 查 `sync.Map` 缓存的 `*glamour.TermRenderer`，未命中则 `NewTermRenderer(glamour.WithStyles(gsStyle), glamour.WithWordWrap(width))` 构造并缓存
- 渲染失败仍原样返回 src（静默降级，不阻塞阅读，现状语义）

### ② internal/ui/pager.go（新文件）— 行级分页

- 纯逻辑 `SplitPages(lines []string, height int) [][]string`：按行切页，可独立表驱动测试
- 终端高度：`term.GetSize`，取不到默认 24 行（预留提示行后取 `height-1`）；stdout 非 TTY（重定向/测试）不分页一次打完
- 渲染后的行含 ANSI 转义但不跨行，按 `\n` 切分安全

### ③ internal/command/view.go — runViewPager 接分页

查阅态两段式按键：

```
渲染全文 → 分页展示
  分页期间：空格/回车=下一页；b=上一页；其他任意键=跳到末页（不误退出）
  末页显示 [e]编辑 [r]刷新 [q]退出 提示（现有循环不变）
```

### ④ 各命令接入

| 入口 | 改动 |
|---|---|
| `runViewPager`（logs / sea / river / spring / plan 共用） | render 结果自然获得新样式 + 分页，零调用点改动 |
| `/show` 各节 body | 知识节 / 日志节 / 面试节拼接后的 body 整体过 `RenderMD`（`【路径】`头与 60 行截断保留）；`runShowPager` 打印节 body 时同样走分页（分页结束回到现有节导航提示 `[n]下一节 [p]上一节 ...`） |
| `/search` viewByKeyword | 命中行以 `#` 开头 → 单行走 `RenderMD` 渲染成标题样式；其余行维持 `HighlightWords` 词高亮（渲染与词高亮叠加互相干扰，故分流） |

## 4. 边界与降级

- 渲染器构造 / 渲染失败 → 原样返回原文（现状语义不变）
- 非 TTY stdout → 不分页一次打完；glamour 输出 ANSI 到管道为业界常规（glow 同），不做特殊处理
- 终端尺寸取不到（极老终端）→ 分页自动关闭一次打完（内容不丢）；渲染宽度回落 90 列

## 5. 测试策略（TDD）

- `render_test`：`## 标题` 渲染后**不含 `## ` 子串**且标题文字保留；代码块 / 列表内容不丢；不同宽度产生不同换行（缓存生效）
- `pager_test`：`SplitPages` 表驱动——空内容 / 单页 / 恰好整除 / 最后一页余行
- 现有 `logs_test` / `show_test` 断言随渲染输出调整（原断言 raw 文本的改为断言渲染后仍含关键词子串）
