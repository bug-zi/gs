## 1. 需求（开发者 2026-10-25 提出）

1. **日志查看语义**：`/logs` 直接查看当前日志；`/logs 261025` 查看 2026-10-25 的日志；当天没有日志则明确说明。
2. **查阅态随时进/出编辑**：日志、计划、笔记（未来三层内容）在查阅的时候时刻可能需要编辑优化——查看态中应能直接进入编辑模式，退出编辑后回到查阅。
3. **Tab 快速补全**：输入 `/` 时就把指令都弹出来；输入完命令（如 `/logs`）后，后面可选择性输入的内容用「浅色注释」形式补充说明。

| 需求点 | 现状 | 差距 |

## 3. 设计方向

### R1 六位日期支持（小）

`logs.go` 的日期解析扩展：4 位数字按 MMDD（今年），6 位数字按 YYMMDD（`workspace.ParseLogDate` 同款格式 `060102`）。两种并存，help 文案同步。无日志提示文案不变。

### R2 查看 pager + 编辑键（中，通用组件）

新增通用查看组件（command 包，如 `view.go`）：

- 流程：渲染内容 → 按键循环 `[e]编辑 [r]刷新 [q]退出`（可按场景扩展键）；
- `e` → `editOpen` 调起编辑器（阻塞）；编辑器退出即「退出编辑模式」，自动重读文件重新渲染，回到查阅态；
- 应用于：`/logs` 单日查看、`/plan` 断点视图；**阶段 2 的 `/sea` `/river` `/spring` 查看直接复用**；
- `/show` 已有自己的五节 pager（含 o/s 键），可在其上补 `e` 键而非重建。

### R3 Tab 补全增强（中，含 spike）

- **一档（readline 原生，低成本）**：补全树加二级节点——如 `/logs` 下挂 `add`/`edit`，`/show` 下挂 `edit`，`/plan` 下挂 `edit`/`next`；输入 `/` + Tab 即列出全部命令（现状已具备，验证即可）。
- **二档（浅色 ghost 提示，需 spike）**：输入时行尾浅色显示建议补全与参数模板（如输入 `/lo` 显示灰色 `gs [关键词|MMDD]`）。ergochat/readline 是否支持 hint/ghost 类 API **未知，需 30 分钟 spike**；不支持则降级：一档 + 候选项内嵌参数模板 + `/help` 文案。
