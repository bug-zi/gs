## 键位表（增量）

| 按键 | 行为 |
|---|---|
| Ctrl+S | **只保存不退出**；状态行提示「已保存 HH:MM」；保存后更新 initial，Esc 判定无改动直退 |
| Ctrl+Q | 保存并退出；保存失败显示错误且不退出 |
| Ctrl+Z / Ctrl+R | 撤销 / 重做。**重做不用 Ctrl+Shift+Z**：Windows Terminal 将其与 Ctrl+Z 发送同一控制字节，无法区分 |
| Ctrl+C | 有选区→复制选区到系统剪贴板（OSC52）；无选区→复制当前逻辑行整行（不含换行） |
| Ctrl+X | 有选区→复制到剪贴板并删选区（入 kill ring）；**无选区=无操作**（决策 1） |
| Ctrl+Y | 粘贴 kill ring 最近条目；**连按轮换**：上一动作也是 Ctrl+Y 时撤销上一次 yank 改插更早条目；任何其他按键打断轮换态 |
| Backspace / Delete（选区态） | 删选区并压入 kill ring；普通输入/Enter/粘贴遇选区=先删选区再执行 |
| Shift+←→↑↓ / Shift+Home / Shift+End | 选区延伸（未激活则以当前光标为锚激活）；非 Shift 移动取消选区 |
| Alt+↑ / Alt+↓ | 上移/下移当前行或列表项块；**编号原样移动**（决策 3）；首行/末行 no-op |
| Ctrl+F | 进查找输入态；Enter 跳下一个匹配并退回 normal；Esc 退出输入态保留高亮 |
| F3 / Shift+F3 | 跳下一个 / 上一个匹配（normal 态可用） |
| Tab / Shift+Tab | 列表行（含已缩进行）按**列表前缀宽度**缩进/反缩进（决策 2：`- `→2、`1. `→3、`10. `→4；反缩进=删行首至多一个前缀宽度空格，下限 0）；非列表行 Tab 插 2 空格、Shift+Tab 删行首至多 2 空格 |
| Ctrl+L | 重绘屏幕（tea.ClearScreen；代码围栏 24 未选，无冲突） |

## 交互语义细则

### 撤销/重做（10）

- 快照栈：每个变更操作入口压入 `{lines 深拷贝, cur, col, want}`，上限 100 条（超出丢最旧）；压栈时清空 redo 栈。
- 覆盖所有变更路径：Insert/Backspace/Delete/Break/Enter（含列表续写）、粘贴、选区删除、Tab 缩进、Alt 移动、Ctrl+X 剪切。Ctrl+Y 轮换内部用 undo 栈实现回退。
- md 文件体量小，O(n) 快照成本可忽略。

### kill ring（9）

- 环形队列上限 20 条；入队来源仅两处：选区删除（Backspace/Delete 选区态）、Ctrl+X 剪切。单字符 Backspace/Delete 不入队（Emacs 惯例）。
- Ctrl+Y 粘贴：插最近条目，光标落条目末尾；连续 Ctrl+Y 在未被打断时轮换（撤销上次插入→插上一条→循环回最新）。

### 选区（15/16/17）

- 状态：`selActive` + 锚点 `(line,col)`；光标为另一端，渲染前归一化为 start≤end。
- 激活后 Shift 系移动延伸；非 Shift 移动、任何使光标重定位的操作取消选区。**Esc 优先级：选区激活时 Esc 仅取消选区，不进入退出确认流**。
- 编辑遇选区：可打印字符/空格=删选区后插入；Enter=先删选区，再在删后位置正常执行 Enter（列表续写按删后位置判断）；粘贴=删选区后整段插入。
- 渲染：按显示行分段反显；光标字符仍用 cursorStyle，选区其余字符用低饱和暗底样式（硬性规则：与主题色相近、禁彩亮）。

### 行/列表项移动（19）

- 当前行为列表项（复用 reBullet/reOrdered）时，块=该项+其后缩进更深的连续行（前导空格数>本行），止于空行或同深/更浅行；非列表行块=单逻辑行。
- 整块与上一/下一块交换；光标跟随到移动后块首行原列（超宽 clamp 到行尾）；有序列表编号不重排。

### 查找（20）

- 纯函数扫描：忽略大小写（决策 4，rune 归一化后比较），产出 `matches[]{line,col,end}`；任何编辑后全量重算（文件小）。
- 输入态（Ctrl+F 进入）：可打印字符追加、Backspace 删除；Enter 跳到光标后下一个匹配并退回 normal；Esc 退回 normal 保留高亮；再次 Ctrl+F 基于旧词可改。
- 跳转循环：到末尾回绕到首；F3/Shift+F3 同向/反向；跳转移动光标并 followCursor。
- 渲染：普通匹配暗色高亮、当前匹配反显；状态行显示「查找: 词 (i/n)」。

### 保存/退出流（1/2/29）

- Ctrl+S 只保存：initial 更新为已存内容 → Esc 无改动直退语义自然成立；savedAt 显示至下次编辑前。
- Ctrl+Q 保存并退出；Ctrl+L 重绘。

```

  buffer.go   # 扩展:快照栈/undo/redo;变更方法入口压栈

  sel.go      # 新:选区归一化/删除/文本提取/显示行分段（纯逻辑）
```

- OSC52 写出经 termenv（lipgloss 既有依赖）输出；需终端支持（Windows Terminal ✓），不支持的终端复制静默无效。

## 终端兼容与实测验证项

- Shift+方向键、Alt+↑/↓、F3 依赖终端发送规范 CSI 序列，bubbletea 原生识别（`KeyMsg.Shift/Alt`）；conhost（老式 cmd 窗口）不支持，Windows Terminal 支持。
- OSC52 同前。两项列入 plan 真机冒烟清单；若实测某修饰键不识别，走 termkey 自研解析兜底（PgUp/PgDn 先例）。
