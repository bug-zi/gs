# gs 自绘输入行（B 路线）— 设计文档

日期：2026-10-26
状态：**已落地**（2026-10-26 实施，plan 已归档）
所属：跨模块全局改动（repl 输入层重构），spec 按机制存放于 `全局/`
前身：`2026-10-25-交互体验打磨-design.md` 的 R3 二档（该轮确认 readline 无 ghost 能力，本轮正式立项替换输入层）

---

## 1. 背景与目标

ergochat/readline 的补全仅 Tab 驱动，无 ghost/候选面板能力（两轮 spike 已确认）。开发者反馈「必须按 Tab」不够顺手，立项用依赖树中已有的 bubbletea/bubbles 自绘输入行，实现现代 shell 体验：

- **边打边弹**：输入即筛选的候选面板
- **ghost 建议**：行尾灰色可接受续写（Tab/→ 上屏）
- **↑↓ 历史**：持久化历史翻阅

## 2. 核心决策

| 决策点 | 结论 |
|---|---|
| 本期范围 | REPL 主输入行替换（含 `ai>` 子模式提示符）；**pager 单键化为非目标**（独立小任务，term.MakeRaw 可单独做） |
| ghost 语义 | ghost = 可接受的续写（Tab/→ 上屏）；参数提示为纯视觉，放候选面板顶部灰字；Enter 只提交缓冲区实际内容 |
| 实现形态 | 每行一个内联 tea 小程序，实现现有 `Reader` 接口；主循环/命令执行/huh 选择器零改动 |
| 历史 | ↑↓ 翻阅 + `~/.gs/history` 持久化（沿用现有文件）；不做 Ctrl-R |
| 降级 | `GS_PLAIN_INPUT=1` 或 stdout 非 TTY 或 tea 启动失败 → plainReader |
| 配色 | ghost/面板沿用 ui 包现有 Dim 色系（硬性规则：与主题色一致） |
| 依赖 | ergochat/readline 整体退役并从 go.mod 移除 |

## 3. 交互规格

| 场景 | 行为 |
|---|---|
| 输入 `/lo` | 行尾灰 ghost `gs`；Tab 或 → 接受上屏 |
| 输入 `/logs `（尾随空格） | 行下弹候选面板：顶部灰字参数提示 `<关键词\|日期>`，下方列子命令 |
| 候选 ≥2 | 面板出现；↑↓ 移动高亮；Enter 采纳高亮项（无高亮移动时原样提交输入）；Esc 关面板 |
| 唯一候选 | 不弹面板，ghost 直接显示剩余部分 |
| ↑/↓（无面板时） | 翻阅历史（最近在前，↑ 向旧） |
| Ctrl-C | 清空当前行重来 |
| Ctrl-D | EOF，退出 gs（与现状一致） |
| `ai>` 子模式 | 同一套输入行，仅提示符不同（SetPrompt 生效） |

## 4. 架构

```
internal/complete/        # 新增：纯逻辑补全源，无 UI 可独立测试
  complete.go             #   For(tree, line) → Result
  tree.go                 #   Cmd{Name, Alias, Subs} → Tree 构建
internal/repl/
  line.go                 # 新增：teaReader——内联 tea model（bubbles/textinput + ghost + 面板），实现 Reader 接口
  history.go              # 新增：历史加载/追加/持久化（纯逻辑）
  input.go                # 改：NewReader 默认 teaReader；GS_PLAIN_INPUT=1 / 非 TTY / tea 失败 → plainReader；readlineReader 删除
  repl.go                 # 改：仅 banner 文案；主循环零改动
```

依赖方向：complete 不 import command（定义 `Cmd{Name, Alias, Subs}` 简单结构，repl 负责映射）；command 不 import complete；互不反向。

### 4.1 complete 包 API

```go
type Cmd struct {
    Name  string
    Alias []string
    Subs  []string
}
type Tree []Cmd
func BuildTree(cmds []Cmd) Tree
type Result struct {
    Ghost      string   // 可接受续写；空 = 无
    Candidates []string // 面板候选；空 = 不弹
    Hint       string   // 面板顶部参数提示；空 = 无
}
func For(tree Tree, line string) Result
```

匹配规则：
- line 不以 `/` 开头 → 全空 Result
- 第一词（`/命令`）未打完：候选 = 前缀匹配的命令与别名；唯一候选 → ghost 剩余部分；多候选 → 面板
- 第一词完整 + 尾随空格：面板列出该命令 Subs，Hint = 该命令参数提示
- 第二词打了一半：面板 = Subs 前缀过滤
- 第二词之后（≥2 个参数位）：仅 Hint
- 匹配一律大小写不敏感（与 exec 的 ToLower 语义一致）
- 各命令的参数提示文本在建树时以表驱动方式显式传入（repl 侧维护：logs→`<关键词|日期>`、sea/river/spring→`<关键词>`、search→`<关键词>`、show→`<主题|edit>`、project→`<名称|edit>`、plan/review/AI 等留空或不提示），无提示则 Hint 为空

### 4.2 数据流

repl.Run → reader.Read()（teaReader）→ 起内联 tea program → input 变化 → complete.For(tree, line) → View 渲染（提示符 + 输入行 + ghost + 面板）→ Enter 返回行文本 → 历史追加落盘 → repl.exec 原流程不变。

### 4.3 提示符

`Reader.SetPrompt("ai> ")` 现有约定保留；teaReader 每次 Read 使用当前 prompt 渲染。

## 5. 错误处理与降级

| 情形 | 处理 |
|---|---|
| `GS_PLAIN_INPUT=1` | 直接 plainReader（无补全无历史，中文绝对正确） |
| stdout 非 TTY（重定向/管道） | 自动 plainReader |
| tea program 启动失败 | 回退 plainReader，Dim 提示一次 |
| 历史文件缺失/损坏 | 从空历史开始，不报错 |
| Ctrl-C | 清行重来（不退出）；Ctrl-D 退出 |

## 6. 测试策略

| 层 | 方式 |
|---|---|
| complete 包 | 表驱动单测：各输入形态 → Result 全字段断言 |
| repl/history | TempDir 读写、追加、损坏容错 |
| teaReader | 薄 UI 不自动测（repl/ui 惯例），真实终端验收 |
| 回归 | 既有全仓测试全绿为底线 |
