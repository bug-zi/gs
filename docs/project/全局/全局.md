# 全局

gs 的全局文档域：承载覆盖多个命令模块的需求正本、设计记录与跨模块硬性规则。

**使用方式**：涉及多个命令模块或整体架构的功能，其 design.md / designs-specs.md / spec / plan 放本目录；单模块功能放 `docs/project/<模块>/`。落地或废弃的 spec/plan 移入本目录 `archive/`。

**本目录内容**：

- `design.md` — gs 1.0.0 整体设计正本（开发者主导维护，AI 不得擅自改写）
- `三层学习框架-design.md` — 三层知识体系（sea/river/spring）跨层框架总本（开发者定稿；原 `学习/design.md` 于 2026-10-27 模块重组时原样迁入）
- `archive/` — 已落地/废弃的 spec/plan 归档处（含 M1、M2+M3 两份实施计划与三层框架三份阶段 plan）

**边界**：`design.md` 的修改权在开发者；AI 只可提建议或经审核协助。
