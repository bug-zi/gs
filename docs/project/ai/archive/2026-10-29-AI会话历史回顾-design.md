# AI 会话历史回顾（/his） · 设计

日期：2026-10-29
状态：**AI 起草，待开发者审核定稿**
所属模块：ai

## 1. 背景与目标

/AI 子模式内无法回看本轮已聊过的问答轮次（上下文里有什么只有 AI 知道）。新增 `/his` 命令：全文翻页回看当前会话历史。

## 2. 决策记录

| 决策点 | 结论 |
|---|---|
| 语义 | **当前会话的往轮回顾**（内存 `st.Hist`），不是 sea/ai 历史存档（后者 /sea 已可查） |
| 展示形态 | **全文翻页阅读**：RenderMD 渲染整篇 → `pagerLoop(pagerFull)` 整篇直出（logs 同策略）；弃「仅清单摘要」与「清单+选中看单轮」 |
| 命令 | `/his`，仅 AI 子模式响应；主模式不注册（维持现有命令空间） |
| 数据范围 | `st.Hist` 现有上限 16 条消息（8 轮），不为本特性调整上限 |

## 3. 行为

- `/his`：`st.Hist` 为空 → 打印 dim「本轮还没有对话」，不进阅读器；非空 → 渲染进翻页视图。
- 视图内容：首行标题「会话回顾 · N 轮」，每轮序号 + `## 问` / `## 答`（格式与存档条目一致，回答为原始 markdown 经 RenderMD 渲染）；问如实取 Hist 存量（含 `@文件` 展开后的文本，不额外保留原始输入）。
- 阅读器按键沿 pager 既有约定：`[q/Esc]` 退出回 AI 模式继续聊，`[r]` 刷新（可收进最新一轮）；`editPath` 返回 false，`[e]` 走既有「本视图没有可编辑的文件」兜底（view.go:185）。

## 4. 代码结构

| 位置 | 改动 |

## 5. 测试

- 渲染文本含标题轮数、每轮序号、问与答原文。
- 空历史不进 pager、输出提示。
- pager 交互沿既有模式不测。
