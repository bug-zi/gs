# AI 输出渲染与每轮存档 · 设计

日期：2026-10-29
状态：**AI 起草，待开发者审核定稿**
所属模块：ai（主）；关联 sea（落盘去向）、plan/roadmap（知识点绑定）、repl（离开询问清理）

## 1. 背景与目标

两个 /AI 体验需求：

1. **富文本渲染**：AI 回答目前流式打印原始 markdown 文本（`##`、`**`、代码围栏字面可见），应渲染为富文本后再显示。项目内其余展示面（/review、日志、plan、tier 查看）均走 `ui.RenderMD`，仅 /AI 例外。
2. **每轮询问添加到 sea**：每次 AI 回答结束后询问是否将本轮问答添加到 sea；确认后系统自动智能归类——绑定到合适的 plan 知识点，找不到则落入未分类。

## 2. 决策记录

| 决策点 | 结论 |
|---|---|
| 渲染时机 | **完成后整段渲染**（弃流式原文与块级增量）：实现可靠、渲染质量完整（代码高亮、表格对齐）；生成期间靠工具步骤行感知进度 |
| 归类语义 | **绑定知识点**：文件物理存 sea/ai/，roadmap.toml 知识点 `sea` 字段追加绑定；与 seaport 的「物理归主题目录」不同轴 |
| 兜底 | 未匹配知识点 / AI 分类失败 / 响应无法解析 → 文件存 `sea/未分类/`，不绑定（与 seaport 兜底一致） |
| 与存量机制关系 | 每轮询问**替代**离开模式时的「存入大海？」询问；`/save` 手动整会话存档保留 |
| 询问粒度 | 每轮一问一答 = 一个条目；回答为空（纯工具轮/出错）不询问 |

## 3. 需求一 · 整段渲染

改动集中在 `AITurn`（internal/command/ai.go）：

- 去掉 `OnDelta` 流式原文打印；保留 `OnToolCall` 步骤行与「（AI 处理中…）」提示行。
- `ag.Run` 返回后若 `final.Content` 非空：`fmt.Fprint(ctx.Out, ui.RenderMD(final.Content))`。
- 单发 `/AI <问题>` 与子模式轮次同代码路径，一并生效。
- 存档文件仍写原始 markdown（渲染仅是显示层，归档语义不变）。

## 4. 需求二 · 每轮询问与智能归类

### 4.1 交互流

每轮 `ag.Run` 成功返回且 `final.Content` 非空 → `confirm`「将本次问答添加到 sea？」（复用现有 huh confirm）：

- **n / Esc**：跳过，无任何副作用；询问本身出错（如非 TTY）一律视为 n，不中断对话。
- **y**：条目生成 → AI 分类 → 落盘绑定 → 打印结果行（`已存入 <路径>（绑定：<知识点标题>）` 或 `已存入 <路径>`）。
- 分类调用期间打印 dim 提示行（同「AI 处理中」风格）。

### 4.2 条目生成

- 格式与 `SaveAIChat` 一致：`> 存档自 /AI 会话 · 时间 · 标题` 引用行 + `## 问` + `## 答`；标题取本轮提问前 30 字。
- 文件名：存档时刻**精确到秒** `2006-01-02-150405`（`CreateEntryIn` 重名即报错，现有分钟精度会同分钟撞名）。

### 4.3 AI 分类（一次调用，temperature 0）

- 候选 = `roadmap.Load(ws.RoadmapFile())` 全部知识点标题，附 branch/group 上下文。
- 系统提示要求：只依据问答内容与候选清单选择唯一知识点，只输出 JSON `{"知识点":"<标题>"}`（容忍围栏与前后杂文本，解析同 seaport `parseClassify` 风格）；不确定时输出空串。
- 校验：返回标题须与 roadmap 中某 Point 精确匹配（忽略大小写）；空 / 不存在 → 视为未找到。
- roadmap.toml 缺失或解析失败 → 直接视为未找到，落未分类（不阻塞存档）。

### 4.4 落盘与绑定

- 匹配成功：文件存 `sea/ai/`，`rm.BindSea(pointRef, rel)` + `roadmap.Save` 原子落盘。
- 未找到：文件存 `sea/未分类/`，不绑定。
- 顺序：先分类后落盘；`roadmap.Save` 失败时文件已存在，明确报错不吞（绑定缺失可后续在 /plan 浏览器 `a` 键补挂）。

### 4.5 清理旧机制

- 删除 `repl.go` 两处 `MaybeSaveAIChat` 调用（/back、/exit 路径）。
- 删除 `MaybeSaveAIChat` 函数与 `AIState.Saved` 字段（`SaveAIChat` 内 `st.Saved = true` 一并清理）；`/save` 命令行为不变。
