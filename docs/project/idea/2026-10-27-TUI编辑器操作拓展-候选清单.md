# TUI 编辑器操作拓展 · 候选清单

> 创建于 2026-10-27 19:11（AI 依据 internal/edit 现有架构整理）

用法：勾选想要的条目（`- [ ]` 改 `- [x]`），键位不合意可直接改写「建议键位」，改完发回给 AI 定案。

## 前置说明

- 普通字符必须原样输入，新功能只能占用 Ctrl / Alt / F 键 / Shift 组合键。项目已有自研 termkey 解析器（PgUp/PgDn 即先例），Ctrl+字母、Alt+字母、Ctrl/Shift+方向键均可扩展。
- Buffer 为纯逻辑层（`[][]rune` + 光标），目前无历史栈、无选区、无查找状态。
- 成本标注：低（几十行内）/ 中（需新增状态或渲染配合）/ 大（跨多模块，不建议近期）。

## 一、保存/退出

- [X]  **1. Ctrl+S 只保存不退出** —— 状态行提示「已保存 HH:MM」，可反复按（建议键位：Ctrl+S；成本：低）
- [X]  **2. 保存并退出另设键** —— 如 Ctrl+Q；或维持现状由 Esc 承担退出（无改动直退/有改动确认）（建议键位：Ctrl+Q；成本：低）

## 二、删除类

- [ ]  **3. 删光标→行尾** —— （建议键位：Ctrl+K；成本：低）
- [ ]  **4. 删光标→行首** —— （建议键位：Ctrl+U；成本：低）
- [ ]  **5. 删前一个词** —— 词=连续字母/数字/汉字段（建议键位：Ctrl+Backspace，Ctrl+W 同义；成本：低）
- [ ]  **6. 删后一个词** —— （建议键位：Ctrl+Delete；成本：低）
- [ ]  **7. 删除整行** —— 光标所在逻辑行整行删除（建议键位：Ctrl+Shift+K 或 Alt+K；成本：低）
- [ ]  **8. 删除整段** —— 段=空行分隔，光标在段中任意位置一键删全段（建议键位：Alt+D；成本：低）
- [X]  **9. 删除内容可粘贴回来（kill ring）** —— Ctrl+Y 粘贴最近一次删除，连按轮换更早的（建议键位：Ctrl+Y；成本：中）

## 三、撤销/重做

- [X]  **10. Ctrl+Z 撤销 / Ctrl+Shift+Z 重做** —— 快照栈方案：每次修改前压整份 lines 拷贝，上限约 100 步；md 文件小成本可忽略；粘贴、列表续写、删行等所有操作天然全覆盖（成本：中）

- 注：Windows 下 Ctrl+Z 不会挂起进程可直接用；跨 Unix 需另处理 suspend，本项目主要跑 Windows 无碍。

## 四、光标移动

- [ ]  **11. 文档首/尾跳转** —— （建议键位：Ctrl+Home / Ctrl+End；g/G 与输入冲突不推荐；成本：低）
- [ ]  **12. 按词移动** —— 词=连续字母/数字/汉字段（建议键位：Ctrl+← / Ctrl+→；成本：低）
- [ ]  **13. 段落间跳转** —— 上一段/下一段段首（建议键位：Ctrl+↑ / Ctrl+↓；成本：低）
- [ ]  **14. 跳转到指定行** —— 底部弹行号输入（建议键位：Ctrl+G；成本：中）

## 五、选择与剪贴板

- [X]  **15. 选区** —— Shift+方向键/Home/End 拖选，渲染反显高亮（成本：中）
- [X]  **16. 选区后一键删除** —— 选区状态下 Backspace/Delete 删选区（依赖 15；成本：低）
- [X]  **17. 选区复制/剪切到系统剪贴板** —— 走 OSC52（Windows Terminal 支持）；无选区时 Ctrl+C 复制当前行（建议键位：Ctrl+C / Ctrl+X；成本：中）
- [X]  **18. Ctrl+V 粘贴系统剪贴板** —— 已有（bracketed paste），无需开发
- [X]  **19. 当前行/列表项上移下移** —— 对调整 md 列表顺序很实用（建议键位：Alt+↑ / Alt+↓；成本：中）

## 六、查找/替换

- [X]  **20. 查找** —— 底部输入，全部匹配高亮 + n/N 或 F3/Shift+F3 跳转（建议键位：Ctrl+F；成本：中）
- [ ]  **21. 替换** —— 逐个确认/全部替换（建议键位：Ctrl+H；成本：大）

## 七、Markdown 编辑增强

- [X]  **22. 列表缩进/反缩进（子列表）** —— 仅列表行生效，普通行 Tab 插空格（建议键位：Tab / Shift+Tab；成本：低-中）
- [ ]  **23. 包裹语法** —— 有选区包选区，无选区插模板光标居中：粗体/斜体/删除线（建议键位：Ctrl+B `**粗体**`、Ctrl+I `*斜体*`、Ctrl+Shift+K `~~删除线~~`；成本：低）
- [ ]  **24. 插入代码围栏** —— ``` 块（建议键位：Ctrl+L；成本：低）
- [ ]  **25. 插入/切换标题级别** —— 对应 # 数量（建议键位：Ctrl+1..6；成本：低）

## 八、视图与其他

- [ ]  **26. 状态行增强** —— 显示保存状态、总行数、字符数、选区长度（成本：低）
- [ ]  **27. 行号列** —— 逻辑行号，需与软换行渲染协调（成本：中）
- [ ]  **28. 鼠标支持** —— 点击定位光标、滚轮滚动（bubbletea 原生支持，Windows Terminal 可用）（成本：中）
- [X]  **29. Ctrl+L 重绘屏幕** —— 花屏自救（注意与 24 的 Ctrl+L 冲突，二者取一）；（成本：低）
- [ ]  **30. 标题折叠** —— md 按标题折叠段落（成本：大，不建议近期）
- [ ]  **31. 自动保存** —— 与现有「Esc 退出确认」语义冲突，不建议

## 键位注意点

- Ctrl+C 传统上是终端复制/中断，用作编辑器内部功能在 Windows Terminal 没问题，但可能与复制习惯冲突；建议复制/剪切统一走系统剪贴板（17）。
- Ctrl+H 传统上是退格，用作替换（21）需确认接受。
- Ctrl+L 在 24（代码围栏）与 29（重绘）间冲突，只能选一个。
