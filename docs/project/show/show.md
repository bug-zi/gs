# show

show 模块文档目录：验收演示（/show 五节视图与 topics 沉淀索引）的需求正本与 spec/plan 归属。

**使用方式**：涉及 `/show` 命令、五节演示视图、`.gs/topics.toml` 沉淀索引、热门关键词提取的功能，其 design.md / spec / plan 放本目录；落地或废弃的 spec/plan 移入本目录 `archive/`。

**本目录内容**：

- `design.md` — show 模块需求正本（AI 起草，待开发者审核定稿）
- `archive/` — 已落地/废弃的 spec/plan 归档处

**边界**：`design.md` 的修改权在开发者；AI 只可提建议或经审核协助。跨命令模块的全局性交互调整放 `全局/`。
